Rwebeya Clinic Management System - Frontend Interface Suite

Folder Structure:
- login.html: Main login portal with automatic role-based email verification routing.
- admin_dashboard.html: Admin portal to register staff, assign roles, and view account statuses.
- receptionist_dashboard.html: Reception desk interface for patient directory search and registration modal.
- doctor_dashboard.html: Doctor queue management and clinical consultation workspace.

Color Palette:
- Primary Forest Green: #1B4D3E
- Accent Sage: #87A96B
- Light Cream Background: #F7F9F6

Instructions:
Open 'login.html' in your browser to navigate through the client-side system logic!
