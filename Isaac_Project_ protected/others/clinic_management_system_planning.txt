               CLINIC MANAGEMENT SYSTEM (CMS) - PROJECT PLANNING
================================================================================

1. PROJECT OVERVIEW & VISION
--------------------------------------------------------------------------------
Project Name: Mini Clinic Management System (CMS)
Target Users: Clinic Staff (Admin, Receptionists, Doctors)
Main Goal:    To digitize patient registration, appointment scheduling, and basic 
              medical record-keeping using a simple web interface and MySQL database.

2. PROBLEM STATEMENT
--------------------------------------------------------------------------------
Many small local clinics still rely on manual paper records, physical appointment 
books, and notebooks to manage patients and doctors. This causes several issues:
  * Slow Retrieval: Finding past patient records in paper files is slow.
  * Scheduling Conflicts: Double-booking appointments occurs frequently.
  * Data Loss Risk: Paper records can easily get damaged, lost, or misplaced.
  * Poor Coordination: Front desk staff and doctors lack instant communication.

Solution:
A lightweight, web-based system that centralizes patient data, tracks appointments 
digitally, and gives staff members role-specific dashboards.

3. PROJECT OBJECTIVES
--------------------------------------------------------------------------------
  1. Digitize paper forms into digital web forms for patients and appointments.
  2. Improve daily clinic workflow for receptionists and doctors.
  3. Ensure data security through user login and MySQL relational database storage.
  4. Apply core Level 4 SWD skills: HTML/CSS/JS (Frontend), Node.js/Express (Backend), 
     and MySQL (Database).

4. PROJECT SCOPE
--------------------------------------------------------------------------------
INCLUDED IN SCOPE (Phase 1):
  [x] Secure user authentication (Admin, Receptionist, Doctor logins)
  [x] Patient registration, search, and directory
  [x] Appointment booking and scheduling
  [x] Doctor daily patient queue and consultation form
  [x] Staff account creation (Admin functionality)

EXCLUDED FROM SCOPE (Future Upgrades):
  [-] Online billing and mobile money payment processing
  [-] Automated SMS / Email appointment reminders
  [-] Complex financial reporting or graphical analytics

5. SYSTEM REQUIREMENTS
--------------------------------------------------------------------------------
FUNCTIONAL REQUIREMENTS:
  1. Authentication: System validates user logins and routes to specific roles.
  2. Patient Management: Search, view, and add new patient records.
  3. Appointment Scheduling: Assign patients to specific doctors with date/time.
  4. Doctor Consultation: Doctors view daily queue, record diagnosis and prescriptions.
  5. Admin Panel: Admin creates and manages clinic staff credentials.

NON-FUNCTIONAL REQUIREMENTS:
  1. Usability: Simple, clean layout easy to navigate on desktop displays.
  2. Performance: Fast database queries without locking or crashing Node.js server.
  3. Maintainability: Simple, modular code written using plain HTML, CSS, Vanilla JS,
     and Express endpoints.

6. RECOMMENDED TECH STACK & TOOLS
--------------------------------------------------------------------------------
  * Frontend:  HTML5, CSS3, Vanilla JavaScript (ES6)
  * Backend:   Node.js, Express.js framework
  * Database:  MySQL (XAMPP / phpMyAdmin / MySQL Workbench)
  * Versioning: Git & GitHub
  * Text Editor: VS Code

7. PROPOSED DATABASE SCHEMA QUICK REFERENCE
--------------------------------------------------------------------------------
  * users        (id, full_name, email, password_hash, role, created_at)
  * patients     (id, full_name, phone, date_of_birth, gender, emergency_contact)
  * doctors      (id, user_id, specialization, phone)
  * appointments (id, patient_id, doctor_id, appointment_date, status, reason)
  * consultations(id, appointment_id, doctor_id, symptoms, diagnosis, prescription)
